# Locomotive-Cabin Active Control (NWU EERI 321)

Python simulation and control design notebooks for the two-cart locomotive-cabin system.

## Notebooks
- `RK4.ipynb`: Open-loop system modelling, state-space formulation, pole-zero analysis, and 4th-order Runge-Kutta simulation.
- `Controller.ipynb`: Classical lag compensator design, frequency-response analysis (Bode plot), and closed-loop RK4 simulation.

## Requirements
- Python 3.x
- NumPy
- SciPy
- Matplotlib
